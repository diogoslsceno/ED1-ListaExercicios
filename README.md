# 📚 Lista de Exercícios — Estruturas de Dados I

Repositório desenvolvido para a **Lista Final da disciplina de Estruturas de Dados**.

O projeto reúne as soluções das **10 questões propostas na lista**, desenvolvidas em **C** e baseadas nos conteúdos e padrões trabalhados durante a disciplina.

---

## 🎯 Objetivo

Aplicar os conhecimentos de **Estruturas de Dados e Algoritmos** na resolução dos problemas propostos pela lista, utilizando implementações em linguagem C.

O trabalho foi desenvolvido em dupla, com a divisão das questões entre os membros.

---

## 👥 Desenvolvimento

O trabalho foi desenvolvido de forma colaborativa, com a divisão das questões entre os integrantes:

* **Questões 01, 03, 05, 07 e 09:** desenvolvidas por **Joel Miranda**.
* **Questões 02, 04, 06, 08 e 10:** desenvolvidas por **Diogo Sales**.

As soluções abordam diferentes situações práticas e utilizam estruturas e algoritmos estudados ao longo da disciplina, incluindo listas, filas, pilhas, ordenação e busca.
